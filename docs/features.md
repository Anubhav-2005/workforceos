# Features

## Shared workspace

- Responsive sidebar and mobile navigation
- Active-route highlighting
- Searchable work activity
- Notification and profile menus
- Local task creation with assignee, priority, and description
- Toast feedback and loading boundaries

## AI employees

WorkforceOS includes three role-based employees:

- **Maya, AI Recruiter** — screens resumes, prepares candidate decisions, and routes approvals.
- **Theo, AI Sales Executive** — prepares contextual outreach and onboarding communication.
- **Nora, AI Customer Support** — monitors support work, resolves routine requests, and prepares human handoffs.

Every employee has a profile, current assignment, progress, status, performance, controls, and an approval surface.
